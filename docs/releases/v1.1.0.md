# HostelXpress v1.1.0 — Android QA

Released source and standalone Android QA build for the November Google Stitch interface update. The current visual differences are accepted for this version; exact visual parity is not claimed.

## Changes

- New Home, Booking, live-tracking and pickup interfaces, orange actions, lavender surfaces, Plus Jakarta Sans fonts and the exported rover photo.
- Three-tab navigation, residence/room/carrier/AWB booking inputs and clearer server-owned payment, unlock and closure states.
- Offline QA Preview preserved, including local sample pickup states. No authentication bypass applies to the real backend.
- Fixed inherited scroll position when moving between application screens.
- App version 1.1.0, Android version code 2. Debug-signed APK for QA upgrades; no production signing claim.

## Verification

See [the Android checkpoint](../reviews/2026-11-17-stitch-android.md) for physical Lava Agni 3 screenshots, comparisons and known design/behavior differences. The versioned artifact's checksum and current GitHub CI results are supplied on its GitHub release.

The application was exercised in offline QA Preview on Android; full TalkBack/large-text/connectivity acceptance, live authentication/payments and physical rover operation remain pending. A preview stage switch does not perform a payment or hardware command. No production deployment is part of this release.

## Install

Download `HostelXpress-v1.1.0-QA.apk` from the v1.1.0 GitHub release. Upgrade over the previous QA installation with the same application ID/signature; preserve app data and do not uninstall merely to upgrade. Choose **Skip sign-in for testing** on the sign-in screen to inspect the interface without a configured backend. Sample state resets when the process restarts.
