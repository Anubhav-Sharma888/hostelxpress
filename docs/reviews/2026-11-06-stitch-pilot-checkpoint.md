## 16 November update — build diagnosis and relaunch

- **The wedged lint-vital phase diagnosed**: with `CPUQuota=200%` + 2-CPU affinity, the Gradle/lint JVMs burned 213% CPU (pinned at the quota ceiling) for 40+ minutes with **zero build-output files written** — the CFS bandwidth quota froze the JVM's worker threads (a known multi-threaded-JVM pathology under CFS throttling). The identical unit had compiled fine under 4-CPU affinity earlier. **Fix applied**: the current build runs with the same mandatory memory caps (MemoryMax 2.3 GB, MemoryHigh 2.2 GB, swap 0) and 2-CPU affinity via `taskset`, but **without CPUQuota** — no CFS bandwidth stalls possible. Early telemetry: memory steady 2.23 GB, affinity `0,1` verified on the Gradle JVM, no pathological throttle rate.
